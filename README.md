# 🚀 Vita OS - Installation

## 📦 Was du hast:

1. **vita-os-KOMPLETT-FINAL.zip** (Hauptdateien)
2. **vita-os-ERGAENZUNG.zip** (Ergänzende Dateien)

---

## ⚙️ Installation (einfach!):

### Schritt 1: Entpacke KOMPLETT-FINAL.zip
```
📁 vita-os/
  ├── data.js
  ├── views/kalender.js
  ├── views/abrechnung.js
  ├── features/patient-form.js
  └── components/kundentacho.js
```

### Schritt 2: Entpacke ERGAENZUNG.zip (in denselben Ordner!)
```
📁 vita-os/
  ├── index.html ⭐
  ├── views/patienten.js ⭐
  ├── styles/kalender.css ⭐
  └── styles/tacho-ergaenzung.css ⭐
```

### Schritt 3: Öffne index.html im Browser
```
Rechtsklick auf index.html → Öffnen mit → Safari/Chrome/Firefox
```

## 🛠️ Bei Problemen:

**CORS-Fehler (manifest.json)?**
→ Normal bei lokalem Betrieb, einfach ignorieren!

**Seite lädt nicht?**
→ Browser-Cache leeren (Strg+Shift+R / Cmd+Shift+R)

**Funktionen fehlen?**
→ Prüfe ob BEIDE ZIPs entpackt wurden!
